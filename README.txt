MS RUIZ CARPINTERÍA - SITIO MULTIPÁGINA

Archivos principales:
- index.html       -> Inicio
- catalogo.html    -> Categorías del catálogo
- contacto.html    -> WhatsApp, Instagram y Facebook
- puertas.html     -> Puertas
- closets.html     -> Closets
- alacenas.html    -> Alacenas
- cocinas.html     -> Cocinas
- muebles.html     -> Muebles
- otros.html       -> Otros trabajos
- styles.css       -> Diseño compartido por todas las páginas
- assets/          -> Logo y favicon

Para sustituir las fotos de ejemplo, puedes reemplazar cada <div class="foto-demo"> por una imagen, por ejemplo:

<img src="assets/puerta-1.jpg" alt="Puerta de madera">

Para contacto, edita contacto.html y cambia los href="#" por los enlaces reales de WhatsApp, Instagram y Facebook.
